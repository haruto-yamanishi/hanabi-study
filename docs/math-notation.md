# 教材の数式表記

`MathText`で教材本文・例題・選択肢・解説・現在地テスト・基礎ドリル・前提診断・復習を表示する。分数、累乗、平方根、積分、行列などはKaTeXで組版する。基礎数学・微積分・線形代数・力学の主要な式を移行済み。未移行の式は従来の文字表記のまま表示する。

インラインは `\( ... \)` または `$ ... $`、独立した式は `\[ ... \]` または `$$ ... $$`。TypeScriptの通常文字列ではバックスラッシュを二重にする。例：

```ts
const theory = '分数 \\(\\frac{1}{3}\\) を通分する。';
const integral = String.raw`\[\int_0^1 x^2\,dx=\frac13\]`;
const matrix = String.raw`\(A=\begin{bmatrix}1&2\\3&4\end{bmatrix}\)`;
```

数式には日本語の説明を混ぜず、通常の文章として式の前後に書く。単位、コード、URLなどを数式らしさから自動変換しない。バッククォート内はそのまま表示する。入力欄では従来どおり数値・分数で回答する。表示だけの移行なので問題ID、正解、採点、データのリビジョン、既存進捗は変えない。

長い式は式の領域内で横スクロールできる。HTMLとMathMLを併記し、読み上げに対応する。KaTeXとフォントはアプリに同梱し、外部CDNへ依存しない。不正な式は本文を壊さず元の式を表示する。生のHTMLは解釈せず、KaTeXの `trust: false` と展開回数上限を使う。

[KaTeX API](https://katex.org/docs/api.html)と[設定仕様](https://katex.org/docs/options.html)を参照。`npm run math:check`で全100,000問・教材・採点問題の数式構文、区切り、コードの扱い、エラー時の表示、HTMLの安全性を確認する。

画面検証は専用の使い捨てブラウザ（CDP 9223）とローカルサーバー（3100）で `HANABI_MATH_BROWSER_TEST=1 npm run math:browser`。テスト用の回答記録が追加される。
