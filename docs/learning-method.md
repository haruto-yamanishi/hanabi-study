# 思い出す反復と説明を組み込んだ教材拡充

塾講師ヒラさんの公開記事を参考に、問題から解法を思い出す反復と、自分の言葉で説明する活動を追加しました。公式教材・監修版ではありません。「血肉化メソッド」という単一の仕様を転載したものではなく、以下の記事で説明された学習の考え方を参考にした設計です。

- [学年１位を取るための６つの勉強法（2022-08-30）](https://www.hirablog.net/entry/2022/08/30/050000)：答えや解法を想起し、確認・修正を繰り返す。
- [受験甘く見てる？（2023-01-03）](https://www.hirablog.net/entry/2023/01/03/050000)：即座に答えられる状態と、言葉で説明できる状態を重視する。

## 教材を増やした範囲

全78スキルに別テーマの応用教材を1本ずつ追加。既存教材の分割ではありません。各教材は原理と適用条件、途中式つき例、2つの説明課題、条件を変えた検証課題、成果物の記録、2つの確認問題を持ちます。

教材総数169本（基礎78・応用78・短編入門13）、採点問題438問、反復カード156題、実習156件、統合制作8件。反復カードは応用教材の説明課題を再利用しているため、438問には重複して加算していません。

応用例：数学の誤差伝播・最小二乗、物理の停止余裕・平行軸、CSの不変条件・並行処理、電装の接触損失・エイリアシング、機械の公差・反映慣性、制御の可観測性・飽和、ロボットの座標変換・構成空間、AIのデータ漏洩・不均衡分類。

## アプリ独自の設計

1. 基礎教材→応用教材で原理と使用条件を学ぶ。
2. 「反復」で解説を見る前に説明を書く。思い出せない場合も、その旨を記入して進める。
3. 解説と比較し、説明できたか自己評価する。誤答時は修正点を必須で記録する。
4. 誤答を最大2題後に再出題する。他の問題が残っていない場合は次に再出題する。途中終了しても回答記録は残る。
5. 別の時間に再確認する。成功後の復習目安は6時間、1日、3日、7日。6時間未満の再成功は成功回数を増やさず、期限も延期しない。誤答で連続成功をリセットする。
6. 実習・統合制作で設計、実装、測定、故障診断、レビューへ接続する。

復習間隔と「成功3回」の表示はHanabi-Studyの運用上の目安で、ヒラさんが指定した数値でも、定着を保証する基準でもありません。初回成功を1回目とし、以後6時間以上離れた成功を加算します。回答時間は記録のみで、自動的な合否判定には使いません。

自己評価はMasterの点数へ加算しません。確認問題と既存の時間を空けたReview、実習の成果物、他者レビューを併用します。実機の技能や専門家水準を読了だけで保証するものではありません。

## 保存と検証

回答・修正点・自己評価・想起時間・日時・教材revisionをブラウザに保存。データ画面のJSON書き出し／読み込みに含みます。従来のJSONも読み込めます。教材revisionが変わった場合、古い反復回答を新しい版の成功回数に数えません。

`npm run content:audit`で78スキルの応用教材、説明課題、確認問題、基礎への参照を検査。`npm run learning:check`で復習時刻、誤答再出題、二重保存防止、永続化、旧データ互換、自己評価で習得点が増えないことを検証します。
