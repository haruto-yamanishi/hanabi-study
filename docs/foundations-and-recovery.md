# 基礎課程・反復ドリル・つまずきからの復帰

## 解決する問題

教科書の説明や例題を読んでも、どの前提で止まったのか分からない学習者が、必要なら中学数学まで戻って確認し、元の問題へ戻れるようにする。大量の問題を順番に全問消化することを目的にはしない。

大日本図書の[新 基礎数学 改訂版の紹介](https://www.dainippon-tosho.co.jp/college_math/fundamental.html)には、確認問題から基本問題、基本問題から教科書を参照する構成が説明されている。Hanabi-Studyではこの学習分野を入口に、独自に作成した前提グラフ・診断・ドリルを提供する。教科書の本文、問題、解答は転載していない。教科書ページとの対応や全範囲の準拠・修了認定を主張しない。

分野の入口として、同社の[線形代数](https://www.dainippon-tosho.co.jp/college_math/linear.html)、[微分積分Ⅰ](https://www.dainippon-tosho.co.jp/college_math/differential1.html)、[確率統計](https://www.dainippon-tosho.co.jp/college_math/probability.html)、[応用数学](https://www.dainippon-tosho.co.jp/college_math/applied.html)を参照した。応用数学の全領域を収録しているわけではない。

## 収録件数

- 新しい基礎課程100単元。各単元に解説、適用条件、典型的な誤り、例題2つ、説明課題と比較ポイント。
- 著者が定義した問題型200種類。それぞれ固定500パラメータの条件違いを含む**100,000問**。
- 80,000問が練習用、20,000問が初見確認用。同じ問題への再回答を新しい問題として数えない。
- 100単元の例題・説明課題、従来の169教材・438採点問題・156説明カード・8制作課題は、100,000問へ重複加算しない。
- 100,000個の独立した概念や授業を作ったという意味ではない。問題型の追加と反復条件の追加を区別する。

分野別：基礎数学8,000、代数・関数8,000、幾何4,000、線形代数8,000、微分積分8,000、解析6,000、確率統計8,000、離散数学6,000、力学18,000、電装5,000、機械4,000、制御5,000、ロボティクス4,000、CS4,000、AI4,000。

[機械可読の全単元・前提・件数](problem-bank-manifest.json)を`npm run bank:manifest`で生成し、CIが収録データとの一致を検査する。難易度は基礎計算と標準的な接続問題を内容から分類し、パラメータが大きくなっただけで上級扱いにしない。

## 学習導線

1. 「基礎・ドリル」から学習分野または単元を選ぶ。既存の全78スキルの教材からも、関連する基礎へ入れる。
2. 考え方、条件、例題を読み、解説を閉じて理由を説明する。説明欄は下書きで、自動採点や保存済みの成果物として扱わない。
3. 基礎ドリルを最大10問ずつ解く。数値・分数・指数表記で回答できる。解法の手掛かりを見た正答は自力正答と区別する。
4. 「わからない・前提からやり直す」で前提診断へ。直近の前提単元を最大2問で確認し、解けなければその前提をさらに確認する。例：PIDから微分、極限、関数、方程式、分数、正負の数へ下がれる。
5. 診断で確認した経路と、元の単元・問題・セットを保持して基礎ドリルへ移る。各問題型で別の2問を自力正答したことを復帰の目安にする。目安未達でも本人が元へ戻ることはできる。
6. 「元の問題・単元に戻る」で中断位置へ復帰。さらに基礎へ戻った場合も最初の問題を保持する。ブラウザ再読み込み後も戻り先を復元する。

診断は原因の断定ではない。少数の確認から復習候補を提案するもので、他の前提まで全て保証しない。最初の不足候補を直した後、元の問題で再確認する。中学の「正負の数」から手動で始め直す入口もある。

## 反復・到達度

回答の正誤を保存してから解説を表示する。誤答・解法を見た回答は修正点を書いて次へ進み、練習では最大2問後に再出題する。同じ問題で再び誤答または補助ありとなった場合は、修正保存後に前提診断へ案内し、元の問題を保持する。初見確認はそのセットでは再出題せず復習へ回す。未入力の問題を勝手に正答と扱わない。

復習目安は6時間、1日、3日、7日、14日、30日。同一セッションで正解を繰り返しても、6時間未満では定着段階を進めず、期限も延期しない。誤答や補助あり回答で定着段階をリセットする。

単元のテスト合格条件は各問題型で異なる確認問題2問の自力正答。合格した時点で教材を飛ばして先へ進める。6時間以上空けた自力正答は別の「定着確認」として記録する。誤答した問題型の過去の合格証拠は無効にし、その後の再テストで回復する。詳しくは[現在地テスト](placement-tests.md)を参照。既存Master点数とは独立し、数値ドリルだけで証明・設計・実機技能を認定しない。解析は入門で、専門分野の代数幾何学は未収録。証明、図による理解、実験、他者レビューは別に必要。

## 保存・規模への対応

問題文100,000件を初期画面へ一括展開しない。安定したIDから必要な問題だけ生成し、単元一覧は10件ずつ表示する。データベースへ保存するのは取り組んだ問題の進捗だけ。

新しいドリル記録と戻り先はIndexedDBに保存し、既存のlocalStorage進捗を保持する。JSON v5書き出しに両方を含め、読み込みと全リセットも対応する。旧版JSONは読み込めるが、新しいドリル記録がないため、この部分は空の状態へ置換される。保存失敗時は画面に表示し、保存成功扱いで進めない。

## 品質検査

- 全100,000問のID・問題文の重複、有限な解答、決定的生成、採点、表示精度、練習／確認の分離を検査。
- 前提グラフの参照・循環、既存78スキルからの入口、監査用内訳を検査。
- 全100単元に独立計算した参照解を置き、数式・符号・単位の代表例を検証。
- 数値入力、初見／再回答の区別、復習間隔、ヒント、診断の再帰、復帰記録を検証。
- ブラウザで回答、誤答修正、前提診断、ドリル、元の問題への復帰、永続化、データ入出力、狭い画面を確認する。

出題型の全ケースを教育効果まで実証したものではない。実際の誤答率、つまずき方、利用者の説明をもとに、問題型そのものを改善していく必要がある。

ブラウザ回帰テストは、検証専用の使い捨てChromiumプロファイル（CDPポート9223）とローカルサーバー（3100）を起動し、`HANABI_BANK_BROWSER_TEST=1 npm run bank:browser`で実行する。テスト用アプリ進捗は初期化される。
