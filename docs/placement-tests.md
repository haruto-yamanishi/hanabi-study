# 現在地テストと達成度の見直し

ホームの「できるところから進む」、ナビゲーションの「テスト」、基礎・ドリルのテスト入口から受験する。分野・単元を指定でき、1回最大3単元または3スキル（最大12問）。途中で中断しても回答済みの結果は残る。合格済みも再テストできる。

## 基礎課程100単元

- 1単元につき2つの問題型を各2問、異なる確認用問題に自力正答すると合格。1問25%、合計100%で単元カードを緑にし、前提確認でも到達済みとして扱う。
- 練習・確認・復習の誤答や「わからない」が発生すると、その問題型の過去の合格証拠を無効にする。もう一方が合格済みなら100%→50%。他の単元には波及させない。
- その場で同じ問題を訂正しただけでは過去の合格は復活しない。誤答より後に異なる確認問題2問へ自力正答すると、その問題型が回復する。
- 確認用問題は未出題を優先。使い切った場合は前回から6時間以上経過した問題を再利用する。即時の答え直しやヒント付き正答はテスト合格の証拠にしない。
- 時間を空けた定着確認は別表示。テスト合格だけで定着済みにはしない。

## FRC・工学78スキル

異なる4問、2種類以上の能力（計算・説明・応用など）への正答を確認する。直近の誤答・未解決より前の回答、旧版の問題、同じ問題の重複は合格証拠に加えない。合格時はスコア90以上・テスト合格としてスキルマップを緑にし、学習順序にも反映する。

その後、現在地テスト・教材チェック・復習などで誤答や「わからない」があればテスト合格を取り消し、スコアを75以下へ戻す。再び4問・2能力を確認すると回復する。定着点はテストでは増えない。教材の閲覧・提出履歴を捏造せず、卒業の知識確認のみテストで代替できる。定着、実習、制作の条件は独立して残す。

## 保存と範囲

スキルは従来のlocalStorage、単元はIndexedDBへ保存する。既存JSON v5に合格時刻・最終誤答時刻も含まれ、入出力・リセットの対象になる。新しいフィールドのない旧データも読み込める。

未受験の前提ノードを上位問題1問から推測で埋めることはしない。少数問による現在地の目安であり、証明・設計・実機作業の修了認定ではない。

`npm run placement:check`で全78スキル・100単元の合格、取消、再合格、同一問題の重複、旧版問題、保存、未解決、ヒント、出題枠の枯渇を検証する。

画面操作の検証は、専用の使い捨てChromiumプロファイル（CDP 9223）とローカルサーバー（3100）を起動して `HANABI_PLACEMENT_BROWSER_TEST=1 npm run placement:browser`。テスト用アプリ進捗を初期化するため、普段のブラウザでは実行しない。
